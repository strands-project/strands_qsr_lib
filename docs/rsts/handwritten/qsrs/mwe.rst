Minimal Working Example
=======================

The *Minimal Working Example* is a simple directional QSR aimed to demonstrate how to implement a new QSR and integrate
it in QSRlib.

Relations
---------
All the possible relations are:

+-------------------+------------------------------------------------+-------------------------------------------------+
| Relation          | Illustration                                   | Interpretation                                  +
+===================+================================================+=================================================+
| left              | .. image:: ../images/mwe_left.png              | Blue object is to the left of red object.       |
+-------------------+------------------------------------------------+-------------------------------------------------+
| right             | .. image:: ../images/mwe_right.png             | Blue object is to the right of red object.      |
+-------------------+------------------------------------------------+-------------------------------------------------+
| together          | .. image:: ../images/mwe_together.png          | Blue and red objects are together.              |
+-------------------+------------------------------------------------+-------------------------------------------------+

API
---
The API of this QSR can be found :mod:`here <qsrlib_qsrs.qsr_new_mwe>`.
